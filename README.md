# Alphabet Inc. (NASDAQ: GOOGL) — Comprehensive DCF Valuation & Financial Modelling

**An independently developed, integrated financial modelling and intrinsic valuation project of Alphabet Inc. (Google), built entirely in Microsoft Excel.**

---

## 1. Project Overview

This project involves developing a comprehensive Discounted Cash Flow (DCF) valuation model to estimate the intrinsic value of Alphabet Inc. The model combines historical financial statement analysis, forward-looking financial projections, free cash flow forecasting and valuation analysis within an integrated Excel workbook.

The objective was to translate historical financial performance into financial forecasts, estimate the company's future cash-generating capacity and determine its intrinsic value using fundamental valuation principles.

The model was independently constructed from scratch, incorporating financial modelling techniques commonly used in corporate finance, equity research and investment banking.

## 2. Model Structure

### A. Historical Financial Statement Analysis (2011–2025)

Developed a historical financial dataset to evaluate Alphabet's financial performance and establish the foundation for future projections.

- Historical income statement analysis.
- Revenue growth and operating performance analysis.
- Profitability and margin analysis.
- Historical financial trend identification.
- Analysis of key financial drivers supporting future forecasts.

### B. Financial Forecasting & Cash Flow Projections (2026–2034)

Developed forward-looking financial projections based on historical performance and key operating assumptions.

- Revenue and operating performance forecasting.
- Forecasting operating profitability.
- Working capital analysis and Net Working Capital (NWC) projections.
- Operating cash flow and free cash flow projections.
- Integration of financial assumptions into the forecasting framework.

### C. Discounted Cash Flow Valuation

Applied the Discounted Cash Flow methodology to estimate Alphabet's intrinsic enterprise and equity value.

- Free Cash Flow to the Firm (FCFF) calculation.
- Weighted Average Cost of Capital (WACC) estimation.
- Cost of equity and cost of debt concepts.
- Terminal value estimation.
- Present value calculation of projected cash flows.
- Enterprise value and equity valuation.
- Intrinsic valuation analysis.

### D. Sensitivity & Scenario Analysis

Evaluated how changes in key valuation assumptions affect the estimated intrinsic value.

- WACC sensitivity analysis.
- Terminal growth rate sensitivity analysis.
- Scenario-based valuation analysis.
- Comparison of valuation outcomes under different assumptions.
- Assessment of key valuation drivers and uncertainty.

## 3. Valuation Methodology

The model follows the FCFF-based Discounted Cash Flow framework:

1. Analyse historical financial performance.
2. Develop financial forecasts based on operating assumptions.
3. Calculate projected unlevered free cash flows.
4. Estimate the Weighted Average Cost of Capital.
5. Calculate terminal value using the perpetuity growth approach.
6. Discount projected cash flows and terminal value to present value.
7. Derive enterprise value and equity value.
8. Conduct sensitivity and scenario analysis to assess valuation robustness.
